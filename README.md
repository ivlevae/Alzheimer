# Human Developing Hippocampus Atlas (HuDeHA) Benchmarks Familial Alzheimer's Disease Brain Organoids

This repository contains the bioinformatics analysis performed to construct the Human Developing Hippocampus Atlas (HuDeHA), an integrated single-cell transcriptomic reference comprising 658,059 cells spanning post-conceptional week 3 to 15.3 years of age, and to benchmark iPSC-derived brain organoids carrying the PSEN1 E280A mutation.

The analysis is separated into the following parts:

1. scRNA-seq reference data processing and quality control

2. Brain organoid preprocessing and reference-based cell class and age mapping

3. Downstream analysis, including cell class composition, jaccard similarity, trajectory inference, and pathway analysis

HuDeHA integrates early embryonic, prenatal, and postnatal single-cell datasets, capturing diverse neuronal, glial, and other cell lineages. The atlas serves as a reference for cell-class annotation and comparison of in vitro brain organoid models with in vivo human neurodevelopmental trajectories.
